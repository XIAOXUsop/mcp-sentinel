# 可复跑评测与性能基线

运行 `python scripts/evaluate.py`，前提是构建完成且已安装 scripts/requirements-validation.txt。结果写入 target/evaluation。

当前集合为 10 个生成模板家族、每族 30 个比较，共 300 组。覆盖 oneOf 重复、enum 内层顺序、嵌套属性、const 文本、必填变化、数值类型放宽，以及四类明确等价的写法。独立 Python JSON Schema 验证器先检查 Schema 和实例见证的前后有效性，再与 Java 实际指纹和阻断结果对照。等价家族的依据来自对应变换的规则，不把有限实例检验当成一般等价证明。

按家族划分 210 个开发样例和 90 个预留家族样例；预留集合第一次用于检查后就不再是未见数据。未来调整规则后需要补充新的服务或家族。当前没有真实服务快照，不能将这些数据宣传为真实服务上的准确率。

另外有 100 个生成的正常工具和 100 个显式指令覆盖探针，用于防止规则意外失效。它们是规则冒烟，**不是计划中要求的 200 个人工独立标注风险样例**，也不能用于声称总体误报率低于 1%。真实样本、独立复核、规则精确率和置信区间仍待试点数据。

性能只测纯比较，不包含进程启动、网络或规则全量扫描。分别测 100／1000 个工具，每组预热 3 次、测量 12 次，记录中位数和 P95。observedHeapBytes 是迭代后的堆使用观察值，不是峰值内存。跨机器结果不能直接比较；正式回退门槛应在固定环境和数据上单独约定。
