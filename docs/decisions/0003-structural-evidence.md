# 结构证据与语义解释分别保存

结构差异按工具出现序号、JSON Pointer、前后值记录，不依赖语义分级是否认识该字段。已识别规则解释具体变化；未识别的输入或注解路径保守阻断。标题 INFO 与嵌套变化同时出现时，后者不能消失。

保留独立 diff.paths 便于人工审阅与机器读取。缺失字段和显式 null 用 beforePresent、afterPresent 区分；数组元素和含斜杠、波浪线的名称使用正确 Pointer 编码。新增或删除子树作为该路径的整体变化记录。

2026-10-17 复审后补充独立覆盖校验：规则必须声明自己解释的字段或明确适用的整个变化（如新增参数、出参整体变更政策）。以同一结构差异集展开这些声明，未匹配的每条实际路径始终追加 DANGEROUS。最终 `changes[].paths` 输出实际覆盖路径，独立于旧逻辑是否已产出其他变化。不能仅凭分级列表非空跳过这一步。

这不等于完整的 Schema 兼容性证明。复杂约束无法判断方向时保留危险或未知影响，不猜测成安全。验证入口为 TrustRegressionTest 的组合变化、未知路径、类型和额外属性样例，以及 OfflineWorkflowTest 的真实 CLI 边界。
