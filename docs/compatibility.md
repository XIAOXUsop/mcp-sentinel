# 协议与资源边界

| 项目 | 当前范围 | 验证证据 |
| --- | --- | --- |
| Java | 21 | 本地 Corretto 21；CI 配置 Temurin 21 |
| MCP SDK | 2.0.1，Jackson 2 适配 | pom 固定依赖及最终 JAR 检查 |
| stdio | 初始化、工具分页、有界字节行和进程树清理 | RawMcpServer、SDK 服务夹具及直接 PID 断言 |
| Streamable HTTP | 初始化、工具列表、请求头引用、超时，JSON 或 SSE 响应 | 本机 HTTP 服务、分块/固定长度超限及 SSE 断开测试 |
| 旧独立 SSE 传输 | 不支持，配置阶段拒绝；与 Streamable HTTP 的 SSE 响应不同 | 配置测试 |
| OAuth 自动登录 | 尚不支持 | 使用显式请求头或环境变量 |
| 协议版本 | 以 SDK 协商结果为准 | 夹具回显客户端请求；不是所有协议版本认证 |
| 最新规范 | 2026-07-28 仅作为规划参考 | 未宣称 SDK 已完整覆盖该规范 |
| 字段 | 六个已采集工具字段 | 指纹、差异与离线回归 |
| 其他元数据与运行时内容 | 不在本阶段覆盖承诺中 | 后续按需求扩展 |

采集分为初始化和逐页请求。每页先检查累计数量，拒绝空或重复游标，最多 100 页。总时间预算为连接超时加两倍请求超时；每页仍受请求超时限制，剩余总预算不足时取消等待并关闭客户端。

默认最多 1000 工具；单定义 1 MiB、累计 16 MiB；规范化最大深度 64。原始单条 JSON 消息上限 16 MiB，累计 JSON 消息上限 32 MiB。stdio 收字节时限制单行与累计字节，stderr 丢弃并限制累计 16 MiB；HTTP 使用 SDK 响应订阅大小限制（含 SSE 行限制），JSON 解析前再累计消息预算。SSE 注释等非 JSON framing 不计入累计 JSON 字节预算，仍受行限制和总等待预算约束。

配置、基线和快照的文件读取上限 32 MiB，使用受限流防止读取时增长。JSON 限制为 100 万 token、嵌套 128、单字符串 2 MiB、字段名 64 KiB、数字长度 1000；进入规范化后仍受深度 64 限制。这些是本候选的固定硬限制，不能用 maxTools 取消。不是操作系统沙箱或对任意恶意子进程的资源隔离承诺。

在线注解在 SDK 带类型转换前校验并保留扩展；已知 hint 的字符串、数字和 null 直接拒绝。stdio 只清理本次启动并追踪到的进程树，先处理后代再处理父进程，清理不完整时扫描失败。刻意自行脱离父进程的程序不属于进程隔离保证。

本地回环测试通过不等于生产服务互操作认证。正式发布需要远端 Linux 与 Windows 实跑；试点应记录服务版本、传输、角色、协商版本和失败样例。
